## 🎯 Обзор

Система представляет собой полнофункциональное решение для автоматизации поддержки с использованием:

- **AI-агенты** на базе LangGraph для обработки запросов
- **Классификация** запросов по категориям (IT, HR, Финансы, Офис)
- **RAG (Retrieval-Augmented Generation)** для поиска в базе знаний
- **Векторный поиск** через Qdrant
- **Интеграция с YouTrack** для создания задач
- **Мониторинг и метрики** через Prometheus + Grafana
- **REST API** на FastAPI с OpenAPI документацией

### Компоненты:

- **FastAPI App** - основное приложение с API и бизнес-логикой
- **PostgreSQL** - реляционная БД для хранения данных
- **Qdrant** - векторная БД для семантического поиска
- **Nginx** - веб-сервер и frontend
- **Prometheus** - сбор метрик
- **Grafana** - визуализация метрик
- **cAdvisor** - мониторинг контейнеров

й разработки (опционально):

- **Python** 3.13+
- **uv** - менеджер пакетов Python (быстрее pip)

## 🚀 Быстрый старт с Docker

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd ml
```

### 2. Создание файла окружения

Создайте файл `.env.development` в корне проекта:

```bash
# Скопируйте шаблон и отредактируйте
cp .env.example .env.development
```

Пример содержимого `.env.development`:

```bash

docker compose --env-file .env.development up -d --build
```

Эта команда запустит:
- PostgreSQL (порт 5432)
- Qdrant (порт 6333)
- FastAPI приложение (порт 8000)
- Nginx (порт 80)
- Prometheus (порт 9090)
- Grafana (порт 3000)
- cAdvisor (порт 8080)
После запуска сервисы доступны по адресам:


- админ панель http://localhost:8000/static/admin.html (там загрузка документов, создание агентов и прочее)

- **Web UI**: http://localhost
- **API**: http://localhost:8000
- **API Docs (Swagger)**: http://localhost:8000/docs
- **API Docs (ReDoc)**: http://localhost:8000/redoc
- **Health Check**: http://localhost:8000/health
- **Qdrant UI**: http://localhost:6333/dashboard
- **Grafana**: http://localhost:3000 (admin/admin)
- **Prometheus**: http://localhost:9090
- **cAdvisor**: http://localhost:8080
